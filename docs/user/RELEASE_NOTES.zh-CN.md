# XIRANG 1.2.0 版本说明

[English](RELEASE_NOTES.md) | [简体中文](RELEASE_NOTES.zh-CN.md)

XIRANG 1.2.0 加强构建隔离与授权，并更新双语控制台，替代 1.1.0。
管理 API 与 Agent 协议保持 `v1`。

## 安全与正确性

- API Token 权限与账户当前权限求交集，账户降权及时生效，既有 Token 不会
  因账户升级而扩大授权。
- flows 元数据要求管理员权限；私有构建产物要求所属者或管理员授权，并检查
  解析后的实际路径。
- 全局 application 发布和节点映射要求管理员审批，旧的未审批映射不参与解析。
- 构建产物通过固定描述符收集，拒绝父目录和叶文件符号链接；本地产物读取会
  非阻塞拒绝 FIFO 等特殊文件。日志持续排空输出，仅保留 64 KiB 尾部。
- 使用同一 OS 身份的构建，在 Controller 和 Agent 进程间串行完成暂存、执行、
  收集和清理；Landlock 限制编译器文件访问，清理失败或进程崩溃会隔离该 UID。
- owned 共享目录递归删除改用目录描述符，拒绝已替换或新增的未跟踪条目。
- Agent 授权检查独立于入站心跳，被撤销、替换或过期的证书不能继续保留可选
  构建节点或交换命令，持续静默的流会到期断开。
- gRPC 升级到 1.83.2、x/text 升级到 0.41.0，并更新必需的传递依赖，处理安全公告。
- 控制器相对状态目录可正常初始化备份；浏览器下载 SBOM 时携带认证并显示失败。

## 控制台

采用中性底色和单一主色，减少重复说明与装饰。导航具有可访问名称和当前页面
状态，登录页可选择语言与主题。切换主题或遥测间隔不再断开终端；浏览器存储
不可用、节点流重连状态、构建者操作权限、窄屏布局和渲染对比度均有回归覆盖。

## 升级要求

升级前备份控制器状态，先升级备用控制器，再升级活动实例。使用当前安装程序，
确保服务权限及主机构建身份锁目录已正确配置。

**原生构建要求启用 Landlock ABI 3 或更高版本（Linux 6.2+）**、专用非 root
身份和委托的 cgroup v2。工具链及依赖需安装在[使用说明](USAGE.zh-CN.md)列出的
标准系统路径。不支持时拒绝执行原生构建；此要求针对原生构建功能。启用构建
节点前应确认主机能力。

管理员需重新保存旧 application 的目标节点映射，以审批其全局解析资格。
构建崩溃或清理失败后，先按[使用说明](USAGE.zh-CN.md)完成 UID 恢复再接收构建。

## 验证与运行边界

发布候选已通过 Go 测试、竞态/静态检查、Linux AMD64/ARM64 编译、API/Proto
合同、Web 审计和 25 项浏览器回归。硬件、MPI、多机 NFS 与 HA 行为仍需站点验证。
浏览器访问 `file://` SBOM 保留既有部署限制。

嵌套共享目录元数据查询、对混合架构 application 显式指定架构过滤仍有既有
限制；后者应使用正确映射并显式选定的节点。

Release 附件包含 Linux AMD64/ARM64 安装包、`SHA256SUMS` 及其 Ed25519 签名
`SHA256SUMS.sig`。请将验证文件与安装包一同保留，安装器会先验证签名和校验和。
