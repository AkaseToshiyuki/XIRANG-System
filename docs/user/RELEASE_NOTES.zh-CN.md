# XIRANG 1.1.0 版本说明

[English](RELEASE_NOTES.md) | [简体中文](RELEASE_NOTES.zh-CN.md)

XIRANG 1.1.0 提供原生 Linux 集群管理与调度，替代版本 1.0.1。
管理 API 与 Agent 协议保持 `v1`。

## 已包含的能力

- AMD64/ARM64 原生执行、资源与执行器检查、队列和用户组策略、任务用量核算，
  以及在具备相应主机能力时的 cgroup v2 隔离。
- 原生构建变体、产物摘要签名、可编辑节点映射，以及调度器和 Agent 两侧的
  显式运行条件检查。映射重叠时使用提交时捕获的首个映射；运行条件不匹配不会
  自动回退到较旧的映射变体。
- 探测路径的精确反向地址对选择、保守容量/RTT 排名、多节点 Gang 分配，
  以及明确报告完成或预算耗尽的有界排名搜索。链路速率是声明边界，
  不是实测应用吞吐；控制器不修改主机路由。
- 独立批量条目的加权分配、共享空间管理、按所有者管理文件与任务、硬件遥测、
  告警和双语控制台。
- 备份恢复和可选 PostgreSQL 单主主备。MPI 适配器需要结合站点启动器与网络验证。

## 相对上一公开版的变化

- 使用 Ed25519 对发布校验清单签名；安装器按内置公钥验证。原生包覆盖两种
  Linux CPU 架构，并包含第三方许可证材料。
- 认证失败保持拒绝，API Token 权限受限，认证入口限流状态有界；Agent gRPC
  流和 keepalive 受到限制，控制器证书可在服务运行期间续期。
- 作业查询使用所有者/活跃状态索引，调度限制单轮处理工作量；节点移除留有审计，
  拓扑排除不可用节点的过期证据，共享空间恢复考虑节点替换。
- 修正亮色主题、拓扑标签、文件管理文字及双语内置模板，并配套浏览器与审计检查。

## 已知运行边界

向嵌套共享目录发布产物，或由不同任务身份读取产物时，可能需要管理员
预先配置文件访问权限。嵌套共享目录列表还有已知元数据查询限制。对含多种架构变体的应用
显式指定架构过滤会被拒绝；该入口修订前，应使用正确映射并显式选定的节点。

依赖硬件的执行行为与 MPI 需要结合站点环境验证。

## 升级与验证

升级前备份控制器状态；先升级备用控制器，再升级活动实例。提交新任务前检查
节点能力和共享文件所有权。协议标识仍为 `v1`，可选能力通过 Agent 协商。

使用当前安装器，并与原生包一同保留 `SHA256SUMS` 和 `SHA256SUMS.sig`。
安装器会在使用前验证签名和校验和。
