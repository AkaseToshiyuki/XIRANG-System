# XIRANG 1.0.1 版本说明

[English](RELEASE_NOTES.md) | [简体中文](RELEASE_NOTES.zh-CN.md)

XIRANG 1.0.1 是面向稳定 `v1` 管理 API 与 Agent 协议的安全和正确性维护版本。
它与 1.0.0 保持协议兼容，不需要迁移数据。

## 1.0.1 修复

- 将面向用户的管理网页中继 TLS 与 Agent mTLS 节点身份分离，避免浏览器流量
  继承节点专用的构建产物权限；
- 将 `github.com/cilium/ebpf` 升级到 0.22.0，修复可达的 BTF 解析漏洞，并按
  当前汇编器校验规则调整手写 eBPF 指令；
- 放置时排除危急网络边，并把缺失时延视为未知值而不是零时延；
- 拒绝非有限 CPU/GPU 放置权重，统一硬件清单与调度使用的拓扑标识；
- 收紧公开源码快照，内部测试、工程记录、研究资料和原始品牌源文件继续只保留
  在私有仓库中。

## 1.0.0 基础版本

XIRANG 1.0.0 是首个稳定的原生 Linux 发行版。它确立 `v1` 管理 API 和 Agent
协议，同时不要求在计算任务与硬件之间部署容器运行时。

### 包含内容

- 面向 AMD64 和 ARM64 Linux 的控制节点或被控节点引导式安装；
- 发行包校验下载、SHA-256 校验、sudo 权限隔离和 NTP 就绪检查；
- Token 或管理员审批接入，以及全网卡链路探测；
- 由角色控制的管理面板、节点硬件清单、GPU 与温度遥测；
- 优先级队列、配额、不可满足请求提前诊断、数组任务、按权重拆分的批量清单、
  多节点 Gang 执行和原生 MPI 适配器；
- 共享空间同步、按所有者隔离的文件管理、原生构建、应用变体、用量核算、告警、
  备份与 PostgreSQL 备用控制器。

## 兼容性

控制平面和 Agent 的协议版本仍为 `v1`。补丁版和次要版本可以增加可选字段和协商
能力，但不会复用 Protobuf 字段号，也不会把已有 OpenAPI 字段改为新的必填项。
升级前应备份控制器，并先升级被动控制器，再切换活动实例。
