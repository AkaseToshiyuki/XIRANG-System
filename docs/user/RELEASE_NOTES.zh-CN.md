# XIRANG 1.3.0 版本说明

[English](RELEASE_NOTES.md) | [简体中文](RELEASE_NOTES.zh-CN.md)

XIRANG 1.3.0 新增持久化集群设置、主机健康、可配置告警和数值历史出口，替代
1.2.0；管理 API 与 Agent 协议保持 `v1`。

## 管理与观测

- 管理员可设置集群名称和 PNG/JPEG Logo，持久化后用于导航、登录页和标题。
- 节点健康汇总可用的 journal、IPMI 传感器、SEL 和机箱信息，区分错误报告、
  硬件纠错、恢复与人工维护记录；采集不可用或仅覆盖部分数据时明确显示。
- 告警设置持久保存触发/恢复时长、严重级别/类型路由和静默截止时间。静默不
  删除原始事件，投递历史记录抑制原因，并提供有界的目标投递状态。
- 认证 Prometheus 接口导出带新鲜度时间戳的数值观测。按[运维说明](OPERATIONS.zh-CN.md)
  配置 viewer 令牌、受信 CA 和独立留存上限。
- Agent 主机事件队列可跨重启和断线保存，显式报告 journal 轮换缺口、队列
  读写失败和淘汰计数。

## 共享存储与兼容性

共享挂载/导出控制改为经 Agent mTLS 通道发送有界命令，并记录回执与审计。
须升级两端，在参与的 root/systemd Agent 显式启用 `-shared-mount-control`；
该选项默认关闭。文件访问继续使用可信管理 SSH，控制流不提供任意 shell。
详见[部署说明](DEPLOYMENT.zh-CN.md)。

共享根目录准备保留已有属主、模式和 ACL 语义，不再覆盖。旧权限不会自动恢复，
请按迁移说明处理，并以受影响的宿主身份核验访问。已修复嵌套共享元数据查询、
混合架构 application 过滤及发布产物的组访问权限。

## 控制台与工程更新

对话框、菜单和提示操作后保留键盘焦点，切换语言保留草稿及终端状态。浏览器
回归覆盖中英文、320 像素布局及自动可访问性检查。

工具链更新为 Go 1.26.10、x/net 0.60.0 及必需的依赖更新。原生构建继续要求
1.2.0 引入的 Landlock ABI 3+、专用非 root 身份和委托的 cgroup v2；未审批的
旧 application 映射仍需管理员审批。

## 升级与运行边界

先创建并验证控制器备份，排空任务后再重启 Agent，保留其 `health-outbox.db`，
不要将该数据库复制给其他节点。PostgreSQL 部署应在两端预置相同 CA、凭据和
稳定 TLS 地址，并先升级被动控制器。保留旧程序和已校验的状态备份用于回滚。

定位灯控制要求宿主单独启用并由管理员授权。监控不会清空硬件日志，或修改电源、
风扇和阈值。历史事件不能证明当前故障或已完成修复。Prometheus 是可选组件，
不会自动安装。同机监控和服务重启不能证明独立高可用。传感器精度、多机 NFS、
物理互连及实际 MPI 负载仍需站点验收；浏览器访问 `file://` SBOM 保留部署限制。

发行验收覆盖 Go 测试、竞态/静态检查、API/Proto 合同、Web 审计、37 项浏览器
回归及 Linux AMD64/ARM64 构建。附件为两个原生安装包、`SHA256SUMS` 和
`SHA256SUMS.sig`；请一同保留。安装器先验证 Ed25519 签名，再验证包摘要。
